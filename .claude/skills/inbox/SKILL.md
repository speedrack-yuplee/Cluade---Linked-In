# 아침 메일 정리

미국에서 밤사이 들어온 메일을 **채널별로 나누고**, 오늘 손대야 할 것만
번역하고 답장 초안까지 만든다. 사용자는 한국시간 08:30에 출근하므로,
그 시점에 30초 안에 하루를 파악할 수 있어야 한다.

## 어디서 메일을 읽나

| 방법 | 조건 |
| --- | --- |
| Microsoft 365 커넥터 (`outlook_email_search`) | 이 대화에서 활성화되어 있어야 함 |
| 사용자가 붙여 넣은 목록 | 발신자 · 제목 · 날짜만 있어도 분류 가능 |

커넥터가 없으면 지어내지 말고 그 사실을 먼저 알린다.
**메일함을 읽을 수 없는데 읽은 척하지 않는다.**

### 전달된 메일의 발신자 주의

`speedrack.kr` 메일은 그룹웨어에서 자동 전달되므로, 겉으로 보이는
발신자가 전부 `halla147@speedrack.kr` 로 찍힌다. **이것을 실제 발신자로
읽으면 분류가 전부 틀린다.** 본문 안의 원본 헤더(`From:`, `Sent:`, `To:`)를
찾아 진짜 발신자를 확인하고, 그 주소로 채널을 판정한다. 본문에 원본
헤더가 없으면 서명과 내용으로 추정하되, 추정임을 표시한다.

## 순서

1. **범위** — 기본은 마지막 확인 이후. 처음 실행하거나 기준이 없으면 최근 24시간.
2. **채널 분류** — `references/channels.md` 의 발신 도메인 기준으로 나눈다.
3. **조치 등급** — 채널 안에서 각 건에 🔴 / 🟡 / ⚪ 를 매긴다.
4. **번역** — 🔴 과 🟡 만 한국어로 옮긴다. ⚪ 는 한 줄 요약만.
5. **답장 초안** — 🔴 중 답장이 필요한 건에 대해 만든다. `email` 스킬의
   문체와 규칙(`.claude/skills/email/references/`)을 그대로 따른다.

## 조치 등급

| 등급 | 뜻 | 판정 기준 |
| --- | --- | --- |
| 🔴 | 오늘 처리 | 기한이 있다 · 돈이나 계정이 걸려 있다 · 사람이 답을 기다린다 |
| 🟡 | 확인 필요 | 판단이 필요하지만 오늘이 마지막 날은 아니다 |
| ⚪ | 참고 | 읽고 넘기면 되는 알림, 자동 발송 |

**기한이 적힌 메일은 무조건 🔴 이다.** 아마존·월마트의 정책·실적 경고,
서류 제출 요구, 대금 공제 이의신청 기한이 여기 해당한다. 놓치면 계정이나
돈이 걸린다.

애매하면 한 단계 올린다. 놓쳐서 생기는 손해가 헛읽는 비용보다 크다.

## 출력 형식

```
# 2026-09-04 아침 메일 — 총 47통

**오늘 처리 3건** · 확인 5건 · 참고 39건
기한: 아마존 서류 제출 9/6 (2일 남음)

---

## 🛒 아마존 (18)

### 🔴 Listing suppressed — B09NLJMGDZ
**원문 요지** (한국어)
...세 줄 이내...

**무엇을 해야 하나**
...한 줄...

**답장 초안** (필요한 경우)
...

### 🟡 ...
### ⚪ 참고 14건
- FBA 입고 완료 알림 6
- 광고 캠페인 리포트 5
- 리뷰 알림 3

## 🏬 월마트 (2)
## 🛋 웨이페어 (0)
## 🎪 Faire (1)
## 🏪 쇼피파이 자사몰 (4)
## 🤝 B2B 거래처·바이어 (2)
## 🚢 물류·창고 (5)
## 🏛 전시회·협회·기관 (3)
## 🗑 광고·스팸 (12) — 유형별 건수만
```

건이 없는 채널은 줄에서 뺀다. 빈 섹션을 나열하지 않는다.
🗑 채널은 **건수와 유형만** 낸다. 하나씩 설명하면 그게 다시 소음이 된다.
단, **사기 의심 건은 발신 주소와 이유를 반드시 밝힌다.**

## 답장 초안 규칙

- 거래 조건(가격, MOQ, 결제, 리드타임)은 **비워 둔다** — `[[MOQ]]` 형태.
  `email` 스킬의 "거래 조건은 건별로 정해진다" 규칙이 여기에도 그대로 적용된다.
- 아마존·월마트 케이스 회신은 감정 표현 없이 사실과 서류만. 사과나 변명을
  넣으면 심사에 불리하다.
- 초안은 **만들기만 한다. 보내지 않는다.**

## 지켜야 할 선

- **읽기만 한다.** 삭제·이동·스팸 처리·발송을 하지 않는다. 초안까지가 끝이다.
- 회사명·발신 주소·요청 내용을 추측으로 채우지 않는다. 없으면 빈칸.
- 메일 본문을 이 저장소에 저장하지 않는다. 공개 저장소이고 상대의 연락처와
  거래 조건이 들어 있다.
