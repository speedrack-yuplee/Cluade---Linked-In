# 아마존 고객 문의 (Buyer-Seller Messaging)

발신 주소가 `@marketplace.amazon.com` 인 메일이다 (`3f8k2j@marketplace.amazon.com`
처럼 익명 주소로 온다). 아마존 알림이 아니라 **실제 구매자가 손으로 쓴 글**이므로,
다른 아마존 메일과 섞지 말고 별도 섹션으로 낸다.

## 왜 따로 보는가

**응답 시간이 계정 지표로 측정된다.** 주말과 공휴일을 포함해 24시간 안에
답하지 않으면 Late Response Rate 가 올라가고, 쌓이면 계정 상태에 영향을 준다.
한국 시간으로 아침에 확인할 때 이미 미국에서 밤사이 온 문의는 시계가
돌아가고 있는 상태다.

**그래서 아마존 고객 문의는 전부 🔴 이다.** 내용이 사소해도 등급을 내리지 않는다.

## 출력 형식

아마존 섹션 안에서 가장 위에 놓는다.

```
## 🛒 아마존 (18)

### 💬 고객 문의 (3) — 24시간 내 응답 필요
| 남은 시간 | 주문/ASIN | 무슨 문의인가 | 유형 |
| 약 6시간 | 111-2345678 / B09NLJMGDZ | 선반 한 칸이 파손되어 도착 | 파손·교환 |

그리고 건마다: 한국어 번역 → 무엇을 물었나 → 영문 답장 초안
```

남은 시간은 메일 수신 시각 + 24시간으로 계산해 적는다. **이미 24시간이
지난 건은 "초과"로 표시하고 맨 위에 둔다.**

## 문의 유형과 답장 방향

| 유형 | 답장의 핵심 |
| --- | --- |
| 제품 사양·호환 문의 | `products.json` 의 치수·하중을 정확히. 추정하지 않는다 |
| 조립 문의 | HANDiLOCK은 볼트가 없다는 점을 먼저. 설명서 위치 안내 |
| 부품 요청 (AS) | 어느 부품인지 사진으로 확인 요청 → 무상 발송 여부는 `[[AS 정책]]` |
| 배송 지연 | 추적번호와 현재 상태를 사실대로. 날짜를 새로 약속하지 않는다 |
| 파손·불량 | 사진 요청 → 교환 또는 환불 제시. 사과는 한 번만 |
| 반품·환불 | 아마존 반품 절차를 안내. 임의로 규정 밖 조건을 만들지 않는다 |
| 대량 구매 문의 | **B2B 채널로도 함께 올린다.** 아마존 메시지 안에서 도매 협의를 하지 않는다 |

## 아마존 메시지에서 금지된 것

정책 위반이 되므로 답장 초안에 절대 넣지 않는다.

- **외부 연락처·링크** — 이메일 주소, 전화번호, 자사몰 주소, 카카오톡
- **리뷰 요청이나 유도** — "좋은 평가 부탁드립니다", 리뷰 수정·삭제 요청
- **할인·쿠폰·사은품 제안** — 보상 조건으로 무엇을 주겠다는 제안
- **마케팅 문구** — 다른 상품 홍보, 브랜드 소개
- 첨부 파일 (사진은 구매자가 보내는 것만 받는다)

대량 구매 문의처럼 아마존 밖에서 이어가야 하는 건은, 답장에서
"별도 채널로 안내드리겠다"고만 쓰고 **주소를 적지 않는다.**
사용자가 다른 경로로 연락하도록 다음 단계에 표시한다.

## 문체

`.claude/skills/email/references/style.md` 를 따르되 더 짧게. 구매자는
실무자가 아니라 소비자다.

- 3~5문장. 인사 한 줄, 답 한 줄, 다음 행동 한 줄
- 전문 용어를 풀어서 쓴다 ("HANDiLOCK joints" → "the frame locks by hand,
  no bolts or tools needed")
- 서명은 이름과 브랜드만. 회사 주소·전화를 붙이지 않는다 (외부 연락처 금지)
