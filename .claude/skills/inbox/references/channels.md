# 채널 분류

**발신 도메인이 1순위 근거다.** 제목이나 내용보다 도메인이 정확하다.
전달된 메일은 본문 안 원본 `From:` 을 봐야 한다는 점을 잊지 않는다.

---

## 🛒 아마존

`@amazon.com` · `@sellercentral.amazon.com` · `@marketplace.amazon.com`
· `@payments.amazon.com` · `@amazon.co.uk` 등 국가별 도메인

가장 많이 오고, 가장 위험한 것이 섞여 있는 채널이다. 아래 순서로 본다.

| 유형 | 등급 | 이유 |
| --- | --- | --- |
| 계정 상태·정책 위반 (Account Health, policy violation, suspension) | 🔴 | 방치하면 판매 중단 |
| 리스팅 차단·삭제 (listing suppressed, ASIN removed, 이미지·문구 반려) | 🔴 | 그 SKU 매출이 멈춘다 |
| 지식재산권·위조 신고 (IP complaint, counterfeit) | 🔴 | 기한 내 소명 필요 |
| 안전·규정 서류 요구 (Prop 65, CPC, 인증서 제출) | 🔴 | 제출 기한이 명시된다 |
| 케이스 회신 (Seller Support case ID 포함) | 🔴 | 사람이 답을 기다린다 |
| 고객 메시지 (Buyer message, A-to-z 클레임) | 🔴 | 응답 시간 제한이 있다 |
| FBA 재고 문제 (입고 지연, 손실, 처분 예정) | 🟡 | 돈이 걸리나 즉일은 아님 |
| 광고 리포트·캠페인 알림 | ⚪ | 자동 발송 |
| 입고 완료·배송 알림·리뷰 알림 | ⚪ | 자동 발송 |
| 판매 리포트, 뉴스레터, 세미나 안내 | ⚪ | |

**case ID 나 날짜가 적힌 아마존 메일은 무조건 🔴 이다.**

## 🗑 광고·영업·스팸

건수와 유형만 낸다. 목록으로 나열하지 않는다.

- 물류·통관·3PL 대행 영업
- SEO·광고 대행, 리스팅 최적화, 리뷰 서비스
- 소싱 에이전트 ("we can find manufacturers") — 우리가 제조사다
- 소프트웨어·데이터·컨설팅 판매, 디렉터리 등재 요금
- 뉴스레터, 웨비나 안내
- 무상 제공만 요구하는 인플루언서·리뷰어

### 사기 의심 — C급이지만 반드시 보고한다

발신 주소 전체와 이유를 함께 낸다.

- 결제 계좌 변경 안내 (거래처 사칭이 가장 흔하다)
- 회사명과 철자가 미묘하게 다른 도메인
- **아마존·월마트를 사칭한 피싱** — 발신 도메인이 `amazon.com` 이 아니거나,
  로그인 링크가 아마존 도메인 밖으로 향한다. 계정 정지를 빌미로
  급하게 로그인시키려는 유형이 많다
- 회신 주소(Reply-To)가 발신 주소와 다르다
- 큰 금액의 발주서를 첨부하며 급하게 확인을 요구
- 선불·보증금·등록비 요구
- 실행 파일이나 암호 걸린 압축 파일 첨부

## 어디에도 안 맞으면

억지로 분류하지 않는다. **기타** 로 두고 등급만 매긴다.
새로운 거래처나 채널이 생긴 신호일 수 있으므로, 반복해서 나타나면
이 파일에 채널을 추가하자고 사용자에게 제안한다.
