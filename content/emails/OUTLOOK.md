# Outlook 메일함 연결하기

메일함을 훑어 거래 가능성 있는 건만 골라내려면 Claude가 Outlook을 읽을 수
있어야 합니다. 계정 인증이라 사용자만 할 수 있습니다.

## 연결 방법

1. [claude.ai](https://claude.ai) → 왼쪽 아래 계정 → **설정 → 커넥터**
2. **Microsoft 365** 를 찾아 **연결**
3. Microsoft 계정으로 로그인하고 권한 승인
4. 새 대화를 열고 `/inbox` 실행

회사 계정이라면 관리자 승인이 필요할 수 있습니다. 이때는 IT 담당자에게
Microsoft 365 커넥터 승인을 요청하세요.

## 연결하면 되는 것

- 메일함 **검색** — 기간과 키워드로 후보를 추림
- 제목·발신자·본문 읽기
- 캘린더 조회 (전시회 미팅 잡을 때)

## 되지 않는 것

- **메일 전체를 한 번에 내려받기** — 검색 방식이라 질의 단위로 가져옵니다.
  실제로도 수천 통을 전부 읽는 것보다 걸러서 읽는 편이 정확합니다.
- **자동 발송** — 답장은 초안까지만 만들고, 보내는 것은 직접 하십니다.
- **삭제·이동·스팸 처리** — 메일함을 건드리지 않습니다. 읽기만 합니다.

## 연결하지 않고 쓰려면

커넥터 없이도 선별은 됩니다. Outlook에서 목록을 긁어 붙여 넣으세요.
**날짜 · 발신자 · 제목**만 있어도 A/B/C 등급은 나옵니다.

```
/inbox
2026-09-01  jane@acmehardware.com   Line review Q1 - storage category
2026-09-01  info@bestlogistics.cn   We can reduce your shipping cost 40%
2026-09-02  buyer@midwestsupply.com Quote request - 2x40HQ shelving
...
```

등급이 나오면 A급 중 볼 것만 본문을 붙여 `/email` 로 넘기면 됩니다.

## 개인정보

메일 본문은 이 저장소에 저장하지 않습니다. 공개 저장소이고 상대의 연락처와
거래 조건이 들어 있기 때문입니다. 남길 가치가 있는 건만 요약 형태로
[`content/emails/`](README.md) 에 직접 넣으세요.
