# 영문 메일 기록

주고받은 영문 메일을 여기에 남기면, 같은 상대에게서 다음 메일이 왔을 때
에이전트가 이전 대화를 먼저 읽고 문맥을 이어서 답장을 씁니다. 지난번에
무엇을 약속했는지 다시 설명하지 않아도 됩니다.

## 쓰는 법

새 메일이 오면 그냥 붙여 넣고 이렇게 말하면 됩니다.

```
/email
(받은 영문 메일 전체 붙여넣기)
```

그러면 순서대로 나옵니다.

1. 한 줄 요약
2. 전문 한국어 번역
3. 읽는 법 — 상대가 진짜 원하는 것, 위험 신호
4. 확인 필요한 항목
5. 바로 보낼 수 있는 영문 답장 초안
6. 그 초안의 한국어 대역
7. 다음 단계

한국어로 "이렇게 답해줘" 라고만 해도 영문 메일로 바꿔 줍니다.

## 파일 추가

**Add file → Create new file** 로 `content/emails/2026-09-03-acme-견적요청.md`
처럼 만들고 [`_TEMPLATE.md`](_TEMPLATE.md) 형식대로 넣으세요. 저장은 남길
가치가 있는 메일만 하면 됩니다.

> 이 저장소가 공개 상태이면 여기 넣은 내용도 공개됩니다. 상대방
> 개인 연락처, 대외비 단가, 계약서 문구는 넣지 마세요.

## 조건이 자꾸 다시 물어지면

MOQ, 결제 조건, 리드타임처럼 매번 되묻는 항목은 [`facts.md`](facts.md) 에
한 번 채워 두세요. 그 뒤로는 답장에 바로 반영됩니다. 비어 있는 항목은
지어내지 않고 `[[MOQ 확인]]` 표시로 남습니다.
